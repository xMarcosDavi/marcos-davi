# Portfólio pessoal de Marcos Davi

Página estática de apresentação profissional, independente dos projetos. Ela reúne uma breve biografia e dá acesso direto ao [Organograma Studio](https://xmarcosdavi.github.io/organograma-studio/) e à [Descrição de Cargos](https://xmarcosdavi.github.io/descricao-de-cargos/). O LinkedIn fica sempre visível no cabeçalho.

[**Abrir o site pessoal**](https://xmarcosdavi.github.io/marcos-davi/)

Abra `index.html` no navegador para visualizar. Para hospedar, publique o conteúdo desta pasta como raiz de um site estático.

As imagens dos projetos são capturas com dados fictícios, guardadas em `assets/`. O conteúdo profissional foi baseado na apresentação pública de [xMarcosDavi](https://github.com/xMarcosDavi).
